GamersHUB

Project guide

Everything behind the hub.

GamersHUB is a social web app where gamers post, chat, follow official updates, and keep their whole gaming life in one place.

Current release: v5.1Updated September 19, 2026PHP + MySQL

Overview

GamersHUB gives each gamer a profile, social feed, friends, direct messages, and a page of game news. The project lives on GitHub under Christian-0777 and is built for community features that feel useful during and between sessions.

Technology

Backend

PHP 8.1 or newer with PDO, MySQL or MariaDB, database-backed sessions, and PHPMailer for SMTP email.

Frontend

Semantic HTML, CSS with Bootstrap patterns, JavaScript, Google Material Symbols, and Simple Icons for social links.

Media

Image uploads use Imagick or GD. Large images are compressed, checked, and stored under randomized file names.

Versioning

Major releases use a number such as 5.0, minor releases use 4.1, and patch releases use three numbers such as 3.2.3.

Architecture

One front controller serves every clean URL, keeping internal file names out of the browser. The code separates JSON endpoints, authentication pages, dashboard pages, shared layout parts, styles, scripts, configuration helpers, database scripts, and upload storage.

Signed-in users can reach Home, Analytics, Messages, Notifications, Friends, My Games, Settings, and Preferences. Each user also has a public profile page.

Features

Accounts

Signup uses verified email, hashed passwords, CSRF protection, three-step onboarding, gamer preferences, platform choices, goals, and favorite games.

Profiles and settings

Profiles include cover photos, avatars, bios, stats, and social links. Settings cover account, gamer preferences, social, privacy, notifications, and security.

Feed and posts

Users publish text, achievements, discussions, questions, LFG posts, and reviews with audience and game-topic controls. Posts support up to 10 images or videos.

Comments and reactions

Posts and comments support reactions, nested replies, sharing, and explicit reply attribution. Writes require an authenticated session and CSRF token.

Friends and notifications

Friend requests support request, accept, decline, cancel, and unfriend actions. Notifications cover follows, reactions, comments, shares, mentions, and system messages.

Messaging

The Messenger-style page includes conversation search, unread counts, emoji, date separators, and polling for new messages.

My Games

Selected games receive update feeds from supported public sources. Source hashing prevents duplicate articles and classifies releases, patches, DLC, news, and more.

Database

The schema covers users, profiles, sessions, games, companies, preferences, posts, media, reactions, comments, notifications, messages, LFG posts, and communities.

Security

Passwords are hashed with PHP's built-in functions. Forms and API writes use CSRF tokens. Sessions live in the database, uploads pass type and size checks, and profile and cover images use randomized storage names.

Setup

  1. Host the app on Apache with URL rewriting, PHP 8.1 or newer, and MySQL or MariaDB.
  2. Install the Composer dependencies.
  3. Import the database schema and starter game data, then apply the migration for older databases.
  4. Add your database and mail-server settings to the environment configuration.
  5. Open the app and test the mail connection with the included check.

Known gaps

Achievements, GClan, and the help center remain placeholder pages. Streams, GClan, and Discover do not have pages yet. The repository also contains a separate dashboard prototype, static previews, a sample game list, and sample uploads.
