Product history

Update logs

A running record of the features, fixes, and improvements that shape GamersHUB.

Minor updatev5.1

Password reset, UTC time, and support navigation

  • Added email and username password reset requests with generic responses that do not reveal whether an account exists.
  • Added one-time hashed reset tokens in password_reset_tokens with one-hour expiration and validation before the password form appears.
  • Added secure reset email delivery, clean /reset/@username links, password confirmation, token invalidation, and reset success states.
  • Fixed encoded username route handling and aligned token expiration with the MySQL database clock.
  • Enforced UTC across PHP, application database sessions, schema setup, and migrations.
  • Added a live local timezone and UTC clock with signed offset and milliseconds to the dashboard header.
  • Added new-tab support links for Wiki, Changelog, Privacy Policy, and Terms of Use.
  • Refined the Wiki into a responsive project guide using the shared /partials/styles.css entrypoint.
Official updatev5.0

Feed discussions, comments, and normalized companies

  • Added feed post detail modals with full post content, selected topics, full-size vertical media, and expandable comments.
  • Added authenticated post reactions, comments, replies, and shares with CSRF protection.
  • Added inline comment expansion and live comment submission on dashboard feed cards.
  • Added nested replies with explicit replied-to attribution, such as "User 2 replied to User 1".
  • Added centralized comment and reply functions through the comments API, including comment reactions.
  • Added selectable game, developer, and publisher topics for posts.
  • Added topic behavior limiting developer and publisher topics to General Update, Discussion, Review, and Question posts.
  • Created normalized company_catalog, game_companies, and user_companies tables.
  • Normalized developer and publisher names so each company is stored once and reused across games and user preferences.
  • Updated feed, account settings, onboarding preferences, My Games, and catalog APIs for normalized company relationships.
  • Added fixed 160x160 dashboard media previews while preserving full-size media in post details.
  • Added reply attribution, comment nesting, comment reactions, and related dashboard interaction fixes.

Official updatev4.0

Gamer's Preference management

  • Added a dedicated Gamer's Preference tab to account settings.

  • Added live game search by game name or developer with catalog API results.

  • Added migration support for the user_developers preference relation.
