Product history

Update logs

A running record of the features, fixes, and improvements that shape GamersHUB.

Patch updatev3.2.1

Post composer and media feed

  • Added a click-to-open post creation modal with the current user's avatar and name.
  • Added audience controls for Public, Friends, Followers, and Only me posts.
  • Added game selection and post types for discussions, questions, looking-for-player posts, achievements, reviews, and general updates.
  • Added image and video uploads with up to 10 attachments per post, five-minute video validation, and server-side media checks.
  • Grouped multi-attachment posts under uploads/post/<username>_<post_id>/ and stored ordered media metadata in post_media.
  • Added responsive feed galleries and collages for posts containing multiple images or videos.
  • Added visibility-aware feed filtering and the Friends visibility option to the MySQL schema and migration.
Minor updatev3.2

Your feed experience

  • Renamed the dashboard home navigation item to Your Feed and added feed-specific navigation.
  • Added a database-backed public feed with Your Feed, Following, and Friends views.
  • Added a CSRF-protected composer for publishing text posts directly to the feed.
  • Added post author details, timestamps, media previews, reaction counts, comment counts, and share counts.
  • Added responsive feed styling and feed search filtering through the shared dashboard search field.
Minor updatev3.1

Community right sidebar

  • Added a shared right sidebar below the dashboard header with responsive desktop and mobile behavior.
  • Added a collapsed-by-default community rail with an in-sidebar toggle.
  • Connected friend activity to the database for mutual friends, online status, selected games, and weekly post activity.
  • Added online friends versus total friends counts.
  • Added a GClan members online placeholder marked as coming soon.
Latestv3.0.1

Shared layout and branding fixes

  • Fixed messaging page sizing and header layout to match the analytics dashboard.
  • Restored shared Bootstrap layout dependencies, coming-soon modal styles, and messaging actions.
  • Updated the shared dashboard latency label to display Ping: <value>ms.
  • Replaced text-based brand marks with the supplied GamersHUB logo across the application.
  • Added the GamersHUB logo as the favicon across page templates.
Official updatev3.0

Messaging experience

  • Added a database-backed Messenger-style messaging page with conversation switching, search, online status, and unread counts.
  • Added message sending, emoji insertion, responsive mobile chat, and realtime polling.
  • Added conversation, participant, and message tables with readable JSON API error responses.
  • Added connection latency measurement and clean internal URL redirects.
